02 — Typography

An org seal, and a neon sign

Two candidate pairings for the same idea: a cold, engraved mark for the organization itself, against a hot, hand-lit title for the game it's forced to play. Both keep Manrope for body/UI text — the thing every surface is missing today is any typeface with character at all.

Option A — Neon tube
Monoton for the game title: drawn like an actual tube sign. Highest impact, best reserved for large sizes (box art, big headers) rather than small UI text.

04 — Production brief

Painting the cast, and the box lid

Two deliverables, one visual language: rim-lit figures against the KALB void, same technique as the silhouette proof above — just with real likenesses instead of placeholder shapes. This section is the practical handoff: reference points for the look, then exact canvas setup for Clip Studio Paint.

Moodboard — rim-light-on-black, comic-neon references

Named artists to pull actual reference images from, not embedded here — search their name plus a keyword or two. Picked specifically for the "black shape, one glowing color" technique the silhouette test above is already built around, not neon in general.

  • Jock (comic covers — Batman, Wytches) — the closest existing match to the silhouette test itself: near-flat black figures against one saturated color field. Search "Jock cover art."
  • Sean Murphy (Batman: White Knight, Punk Rock Jesus) — high-contrast noir linework with a single accent color doing all the emotional work. Search "Sean Murphy White Knight art."
  • Josan Gonzalez (Judge Dredd covers, cyberpunk illustration) — denser, more rendered take on neon-on-black; good reference if a character wants more surface detail than a pure silhouette. Search "Josan Gonzalez illustration."
  • Ian McQue — industrial figures picked out by strong colored rim-light against near-black grounds. The best reference for the "light escaping something dark" rule below. Search "Ian McQue sketches."
  • Yoji Shinkawa (art director, Metal Gear Solid) — looser ink-wash figures with dramatic single-color glow. Reference if a character calls for more energy/motion than precision. Search "Yoji Shinkawa MGS art."

The four rules already written for this project (§06 below) still govern every character: black is a surface, not an absence; red and gold never compete; a character's neon is theirs alone; light should look like it's escaping something dark.

Character portraits — canvas setup

The card is built at tarot proportions (confirmed directly from baseline.html's card CSS: 350×600px, a 7:12 ratio) — matching this exactly means the final painting drops in with zero cropping surprises.

SettingValue
Trim size70 × 120mm
Bleed+3mm each edge → 76 × 126mm canvas
Resolution300 dpi (350–400 dpi for extra zoom headroom)
Basic expression colorColor
Color modeRGB — not CMYK
At 300dpi, canvas ≈898 × 1488 px

RGB matters here specifically: every color in this project (this page included) is a web hex value — #B0102F, #FBBF24, each signal color — and CMYK conversion would visibly shift them, especially the reds and golds.

Clip Studio Paint — New Canvas steps

  • File → New. Set the unit dropdown to mm, width 76, height 126.
  • Resolution: 300 (or 350–400 if you want extra headroom).
  • Basic expression color: Color.
  • If your CSP version offers a template/margin option in the New Canvas dialog, set a 3mm margin on all sides to mark the bleed — otherwise, add a guide layer by hand at 3mm from each edge (Ruler tool, or View → Grid/Guides) once the canvas is open, so you can see trim vs. bleed while you paint.
  • Paint at full canvas size (bleed included); keep the face/key silhouette detail centered in the open middle band above.
  • Export: flatten, crop to the 70×120mm trim (drop the bleed), save as .jpg under the exact filename from the table above. Keep the layered .clip master (bleed included) as the archive.

06 — Reference

Style guide summary

TokenValueRole
Void#0A0710Dominant ground — never fully flat, lean toward warm/oxblood in gradients.
KALB Red#B0102FOrganizational accent — authority, danger, dividers. Never used as a character's own color.
KALB Gold#FBBF24Primary structural accent — borders, active states, victory.
—10 signal colorsExclusive to each character's own accents; never used for general UI chrome.
  • Black is a surface, not an absence. Every dark ground carries a faint red or gold gradient — pure flat black reads unfinished.
  • Red and gold never compete. Gold structures the page; red marks anything that speaks with the organization's authority.
  • A character's neon is theirs alone. It never becomes a shared UI color — that's what keeps ten characters feeling distinct.
  • Light should look like it's escaping something dark. Favor rim-light and glow over flat fills whenever a neon color meets black.
