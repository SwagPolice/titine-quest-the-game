# KALBLAST

A series of drinking board games with RPG elements, created by Paul Arzelier and Côme Delobelle.

**[Play now →](https://swagpolice.github.io/kalblast-the-game/)**

There are two games in the series:
- **[Complete Version](complete-version/README.md)** — the full game: rulebook, 10 character classes, and a 60-room board, with printable cards/board and an in-browser rulebook, ready to play with friends.
- **[Quick Version](quick-version/README.md)** — a smaller, faster 27-box variant meant to be carried anywhere. Still an early-stage concept — only a board design sketch exists so far.

See [ROADMAP.md](ROADMAP.md) for what's planned next. Licensed under [CC BY-NC-SA 4.0](LICENSE).
